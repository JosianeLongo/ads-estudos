
# Variáveis

 Variável é uma caixa que guarda informações.

## Exemplo

idade <- 30

A variável idade guarda o valor 30.

## Tipos de Variáveis

### Inteiro

Guarda números sem vírgula.

Exemplo:

idade <- 27

### Real

Guarda números com vírgula.

Exemplo:

nota <- 8.5

### Caractere

Guarda textos.

Exemplo:

nome <-  "Josiane"


## Exercícios

### Exercício 1

inteiro idade

idade <- 27

escreva(idade)

Resultado:

27

### Exercício 2

caractere nome 

nome <- "Josiane"

Resultado:

Josiane

### Exercício 3  

inteiro idade

idade <- 30

escreva ("idade")

Resultado:

idade

## O que aprendi

- Variável é uma caixa que guarda informações.
- leia() é entrada de dados
- escreva() é saída de dados.
- <- é atribuição
- Texto fica entre aspas.
